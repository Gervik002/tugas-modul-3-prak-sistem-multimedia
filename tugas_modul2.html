🔊 1. HTML5 Audio

Sebelum HTML5, file audio hanya dapat diputar di browser menggunakan plug-in (seperti Flash). Elemen <audio> HTML5 menentukan standar untuk menyematkan audio di halaman web.

Contoh Audio Player

Contoh pemutar audio menggunakan elemen <audio>

Kode HTML:

<audio controls>
  <source src="horse.ogg" type="audio/ogg">
  <source src="horse.mp3" type="audio/mpeg">
  Browser Anda tidak mendukung elemen audio.
</audio>

Penjelasan:

  • Atribut controls menambahkan kontrol audio seperti play, pause, dan volume.
  • Elemen <source> memungkinkan Anda menentukan file audio alternatif.
  • Browser akan menggunakan format pertama yang dikenali.

🎬 2. HTML5 Video

Sebelum HTML5, video hanya bisa diputar di browser menggunakan plug-in (seperti Flash). Elemen <video> HTML5 menentukan cara standar untuk menyematkan video di halaman web.

Contoh Video Player

Contoh pemutar video menggunakan elemen <video>



Kode HTML & JavaScript:

<video id="myVideo" width="420" controls>
  <source src="mov_bbb.mp4" type="video/mp4">
  <source src="mov_bbb.ogg" type="video/ogg">
</video>

<button onclick="playPause()">Play/Pause</button>
<button onclick="makeBig()">Big</button>
<button onclick="makeSmall()">Small</button>
<button onclick="makeNormal()">Normal</button>

<script>
var myVideo = document.getElementById("myVideo");
function playPause() {
  if (myVideo.paused) myVideo.play();
  else myVideo.pause();
}
function makeBig() { myVideo.width = 560; }
function makeSmall() { myVideo.width = 320; }
function makeNormal() { myVideo.width = 420; }
</script>

Penjelasan:

  • Atribut controls menambahkan kontrol video (play, pause, volume).
  • Atribut width dan height menentukan ukuran video.
  • Atribut autoplay membuat video bermain otomatis saat halaman dimuat.
  • JavaScript digunakan untuk mengontrol video secara dinamis (play/pause, ubah ukuran).

Format Video yang Didukung HTML5

▶️ 3. HTML YouTube Videos

Cara termudah untuk memutar video di HTML adalah menggunakan YouTube. YouTube akan menampilkan id video (seperti tgbNymZ7vqY) yang bisa digunakan dalam kode HTML.

Langkah-langkah:

  1. Upload video ke YouTube
  2. Catat ID video
  3. Definisikan elemen <iframe> di halaman web
  4. Arahkan atribut src ke URL video
  5. Gunakan atribut width dan height

Contoh YouTube Embed (iframe)

Kode HTML:

<iframe width="420" height="315"
  src="https://www.youtube.com/embed/tgbNymZ7vqY">
</iframe>

Parameter YouTube

Parameter Nilai Keterangan
autoplay 0 (default) / 1 0 = tidak autoplay, 1 = autoplay saat dimuat
loop 0 (default) / 1 0 = putar sekali, 1 = putar berulang
controls 0 / 1 (default) 0 = sembunyikan kontrol, 1 = tampilkan kontrol

Contoh dengan Autoplay:

src="https://www.youtube.com/embed/tgbNymZ7vqY?autoplay=1"

Contoh dengan Loop:

src="https://www.youtube.com/embed/tgbNymZ7vqY?playlist=tgbNymZ7vqY&loop=1"

Contoh tanpa Controls:

src="https://www.youtube.com/embed/tgbNymZ7vqY?controls=0"

Metode Embed Lainnya (Deprecated)

Catatan: YouTube <object> dan <embed> sudah deprecated sejak Januari 2015. Disarankan menggunakan <iframe>.

<!-- Menggunakan object (deprecated) -->
<object width="420" height="315"
  data="https://www.youtube.com/embed/tgbNymZ7vqY">
</object>

<!-- Menggunakan embed (deprecated) -->
<embed width="420" height="315"
  src="https://www.youtube.com/embed/tgbNymZ7vqY">

📍 4. HTML Geolocation API

HTML Geolocation API digunakan untuk mendapatkan posisi geografis pengguna. Karena ini dapat mengompromikan privasi, posisi tidak tersedia kecuali pengguna menyetujuinya.

Demo Geolocation

Klik tombol untuk mendapatkan koordinat Anda

Menunggu aksi pengguna...

Kode HTML & JavaScript:

<button onclick="getLocation()">Try It</button>
<p id="demo"></p>

<script>
var x = document.getElementById("demo");
function getLocation() {
  if (navigator.geolocation) {
    navigator.geolocation.getCurrentPosition(showPosition);
  } else {
    x.innerHTML = "Geolocation is not supported";
  }
}
function showPosition(position) {
  x.innerHTML = "Latitude: " + position.coords.latitude +
  "<br>Longitude: " + position.coords.longitude;
}
</script>

Penjelasan:

  1. Cek apakah Geolocation didukung oleh browser
  2. Jika didukung, jalankan method getCurrentPosition()
  3. Jika berhasil, mengembalikan objek koordinat ke fungsi showPosition
  4. Fungsi showPosition() menampilkan Latitude dan Longitude

Property yang Dikembalikan getCurrentPosition()

Property Keterangan
coords.latitude Latitude dalam angka desimal (selalu dikembalikan)
coords.longitude Longitude dalam angka desimal (selalu dikembalikan)
coords.accuracy Akurasi posisi (selalu dikembalikan)
coords.altitude Ketinggian dalam meter di atas permukaan laut
coords.altitudeAccuracy Akurasi ketinggian posisi
coords.heading Arah dalam derajat searah jarum jam dari Utara
coords.speed Kecepatan dalam meter per detik
timestamp Tanggal/waktu respons

Drag and Drop API memungkinkan pengguna untuk menyeret dan melepaskan elemen HTML. Fitur ini sangat berguna untuk membuat antarmuka yang interaktif.

Langkah-langkah Drag and Drop:

  1. Membuat elemen draggable: Tambahkan atribut draggable="true"
  2. ondragstart + setData(): Menentukan data yang akan diseret
  3. ondragover: Menentukan area drop dengan event.preventDefault()
  4. ondrop: Menangani aksi saat elemen dilepaskan

Kode HTML & JavaScript:

<!-- CSS -->
#div1, #div2 {
  float: left; width: 100px; height: 35px;
  margin: 10px; padding: 10px;
  border: 1px solid black;
}

<!-- JavaScript -->
function allowDrop(ev) { ev.preventDefault(); }
function drag(ev) {
  ev.dataTransfer.setData("text", ev.target.id);
}
function drop(ev) {
  ev.preventDefault();
  var data = ev.dataTransfer.getData("text");
  ev.target.appendChild(document.getElementById(data));
}

<!-- HTML -->
<div id="div1" ondrop="drop(event)" ondragover="allowDrop(event)">
  <img src="logo.gif" draggable="true" ondragstart="drag(event)" id="drag1">
</div>
<div id="div2" ondrop="drop(event)" ondragover="allowDrop(event)"></div>

Penjelasan:

  1. preventDefault() mencegah browser menangani data secara default (membuka sebagai link)
  2. dataTransfer.getData() mendapatkan data yang telah diset di setData()
  3. Data yang diseret adalah id elemen ("drag1")
  4. Elemen yang diseret ditambahkan ke dalam elemen drop
